# Personas [DRAFT]

## Persona 1: Field Agent (primary)
- **Name:** Rahul, 32
- **Role:** Visits 4-8 hospitals per day
- **Device:** Mid-range Android, sometimes iPhone
- **Context:** Moving, one hand free, bright sunlight, patchy network in basements and wards
- **Needs:** Know today's route, quick check-in, record work fast, proof that he visited
- **Frustrations:** Re-entering data, app freezing, losing data when network drops
- **Design implications:** Big buttons, few taps, offline-first, clear sync status, simple language

- Assigns visits and reviews reports in the web dashboard.
- Impacts the app only through the data and rules the backend sends.
