# Glossary [DRAFT]

| Term | Meaning |
|---|---|
| Agent | A field user of the app |
| Visit | One assigned task to go to a hospital and do work |
| Hospital | A location an agent visits |
| Check-in | Recording arrival with GPS and time |
| Check-out | Recording departure and completion |
| Visit form | The data the agent fills during a visit |
| Sync queue | Local list of pending writes to send to the server |
| Idempotency key | Unique ID per write so retries do not create duplicates |
| EAS | Expo Application Services (build, submit, update) |
| OTA | Over-the-air JavaScript update without a store release |
| ADR | Architecture Decision Record |
