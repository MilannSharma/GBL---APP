# Field Agent App: Documentation

Mobile app (iOS + Android) for field agents who travel to different hospitals.
Stack: **Expo + React Native + TypeScript**. Backend APIs are provided by a separate team.

## How to use these docs

Start at `00-plan`, then read in order. Every feature and every screen has its own file, so a developer can pick one file and build one thing.

| Folder | What is inside | Who reads it |
|---|---|---|
| `00-plan/` | Project plan, phases, team, milestones | Everyone |
| `01-product/` | PRD, scope (in/out), user flows, personas, glossary | PM, design, devs |
| `02-features/` | One spec file per feature | Devs, QA |
| `03-pages/` | One spec file per screen | Devs, designers, QA |
| `04-engineering/` | Setup, architecture, scalability, folder structure, offline sync, testing, CI/CD | Devs |
| `05-security/` | Security model, privacy and compliance, threat checklist | Devs, security, legal |
| `06-ui/` | Design system, UI guidelines, references, accessibility | Designers, devs |
| `07-api/` | API conventions + **blank** endpoint templates for the backend dev to fill | Backend dev, mobile dev |
| `08-project/` | Roadmap, risks, decisions (ADR), QA and release checklists | PM, QA |
